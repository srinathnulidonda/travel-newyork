## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/srinathnulidonda/travel-newyork.git

# Navigate to folder
cd new-york-explorer

# Open with live server
# Right-click newyork.html → "Open with Live Server"
```

**That's it!** No build process, no dependencies to install. Just open and enjoy. ⚡
